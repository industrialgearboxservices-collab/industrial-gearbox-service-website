Quarterly Industrial Gearbox Lead-Time Index

Methodology and data definitions

This standalone proposed methodology describes a proposed, repeatable way to summarize dated new-unit quotations and completed rebuild jobs. The rules must be finalized against the records available before a real edition is calculated.

Draft protocol, not an audited study. The paired sample values shown on the index page are synthetic design examples. No company quotes, customer jobs, or supplier records were analyzed to create this sample.

1. Unit of observation and eligibility

New-unit OEM quotes

  • One record represents one dated quote for a new industrial gearbox with an identifiable gear type and configuration.
  • Include only quotes within the stated 90-day collection window and retain a source record for audit.
  • For revised quotes on the same configuration from the same supplier, use the latest eligible revision; report the deduplication rule with the edition.
  • Exclude canceled, expired, undated, duplicate, or scope-ambiguous records from the primary calculation and disclose counts excluded.

Completed rebuild jobs

  • One record represents one completed gearbox rebuild with documented receipt and tested-ready-to-ship dates.
  • Exclude canceled, incomplete, missing-date, and duplicate job records from turnaround calculations.
  • Use elapsed calendar time; include approval and parts waits in total turnaround, then break them out separately only when timestamps are reliable.
  • Keep emergency jobs separate from routine work, and disclose how rush jobs are identified.

2. Coverage and classification

Candidate gear classes are helical, planetary, worm, and bevel. Classify each record from its quote or inspection documentation, not from a guess. Custom one-off or hybrid units should be reported in a separate category or excluded from standard-class summaries.

Geography: publish only the regions represented by eligible records; do not describe a local sample as national. Horsepower and torque: do not set arbitrary inclusion limits. First review the available records, then publish the covered ranges by class and identify missing ratings. If these fields are unavailable, state that the edition does not stratify by power or torque.

3. Clock definitions

OEM quoted lead time

Proposed measure: quote date to the quoted shipment-ready date. Record whether transit, installation, and commissioning are included; do not mix delivery dates and ship dates in one statistic.

Rebuild turnaround

Proposed measure: shop receipt to tested and ready-to-ship date. It does not mean delivery, installation, or return to service. State whether the clock is paused for customer approval; the default proposal is elapsed time without pausing.

4. Summary statistics

Report the median, sample count (n), IQR, and minimum-maximum range for each eligible class and measure.

Median = middle ordered value (or mean of two middle values for even n)
IQR = Q3 - Q1
Range = observed minimum to observed maximum

For continuity in this sample, quartiles use inclusive linear interpolation (Type 7). A published edition must keep one quartile method across releases and state it. Small sample counts should be called out; suppress or combine a class when the predeclared minimum sample rule is not met. Show the rule before analysis, not after seeing the results.

Compare the OEM quote cohort and rebuild cohort as separate observational groups unless records are genuinely matched for equivalent gearbox specification and scope. Do not present a difference between separate medians as a guaranteed saving or as proof one option is faster for an individual buyer.

5. Data quality, privacy, and revision control

  • Maintain an internal source register with record IDs, source dates, and inclusion decisions.
  • Remove customer names, plant identifiers, supplier quote numbers, serial numbers, and commercially sensitive terms from public files.
  • Document missing fields, exclusions, duplicate handling, date normalization, and any corrections.
  • Version every release; keep prior editions available as static archives and never silently overwrite historical figures.
  • Recalculate and review the published table, chart, CSV, PDF, and page text from the same approved dataset.

6. Publication schedule and release gate

Proposed cadence: target publication on the second Tuesday after quarter-end. Publish only after record review, privacy screening, calculations, and an independent accuracy check are complete. If the release gate is not met, delay publication and show a revised date; do not fill a gap with estimates.

Each edition should state the exact data-window start and end dates, publication date, covered geography and classes, record counts, methodology version, and a named accountable reviewer whose role is accurate.

7. Dataset metadata and discoverability

For a real public edition, Dataset structured data can describe the dataset, its creator, measured variables, temporal coverage, and downloadable distribution. Markup must match visible page content and an actual downloadable dataset. The linked sample page uses Dataset markup to identify its synthetic sample; its time coverage is intentionally omitted because the fictional values have no real observation dates.

Structured data can help machines understand a dataset, but it does not guarantee search display, rankings, press citations, or backlinks.
